# Models

Put model weights here. They are git-ignored (`*.pt`) because of their size.

| File | Used for | How to get it |
|---|---|---|
| `emergency_vehicle.pt` | Ambulance, fire truck, police car detection (optional) | Train it: [docs/TRAINING.md](../docs/TRAINING.md) |

The general vehicle model `yolov8n.pt` is downloaded automatically by
Ultralytics on first use.
