Emergency vehicle detection dataset

Class IDs in this prepared dataset:
0 = ambulance
1 = fire_truck
2 = police_car

Original split names were train, valid, and test. The valid split has been renamed to val.
Original class IDs were Police=0, ambulance=1, firetruck=2 and have been remapped to the IDs above.
